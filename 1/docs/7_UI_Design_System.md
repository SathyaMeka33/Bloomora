# Bloomora UI Design System

Version: 1.0

Status: Draft

Last Updated: July 2026

---

# Purpose

This document defines every visual rule used in Bloomora.

Every page, component, animation, spacing, typography, and interaction must follow these guidelines.

Consistency is mandatory.

---

# Design Philosophy

Bloomora should never look like a traditional e-commerce website.

Bloomora should feel like

Luxury

Warm

Minimal

Elegant

Premium

Trustworthy

Modern

Emotional

Customers should feel calm, not overwhelmed.
